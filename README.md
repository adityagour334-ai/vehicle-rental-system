# Vehicle Rental System

A command-line based Vehicle Rental System developed using Python.
The project allows users to view available vehicles, rent vehicles, return vehicles, and generate rental invoices.

## Features

- View available cars and bikes
- Rent a vehicle
- Return a rented vehicle
- Calculate rental cost
- Generate a rental invoice
- Check vehicle availability
- Input validation for rental duration and vehicle ID
- Object-oriented programming using classes and inheritance

## Vehicle Types

The system currently includes:

- Cars
  - Toyota Camry
  - Honda Civic
- Bikes
  - Yamaha R15
  - Royal Enfield Classic 350

## Requirements

- Python 3.x
- No external Python libraries are required.
